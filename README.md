# 📱 PhoneView - เว็บแนะนำสเปกมือถือและแนะนำร้าน

เว็บแอปพลิเคชันสำหรับค้นหาและแนะนำสเปกสมาร์ทโฟน/แท็บเล็ต คัดกรองตามงบประมาณและฟีเจอร์การใช้งาน 

🌐 **ทดลองใช้งานจริง (Live Demo):** 
[https://phoneview-vercel-git-main-opnsoftware8-makers-projects.vercel.app](https://phoneview-vercel-git-main-opnsoftware8-makers-projects.vercel.app)

## 🛠️ Tech Stack
* **Framework:** Next.js (React)
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
* **Performance:** Lighthouse Score 99 (Desktop) / 85 (Mobile)

## ✨ Features
* คัดกรองตามประเภทอุปกรณ์ (Smartphone / Tablet)
* คัดกรองตาม Price Tier และลักษณะการใช้งาน (Gaming, Camera, Battery ฯลฯ)
* ระบบค้นหาชื่อรุ่นแบบ Real-time
* รองรับการแสดงผลทุกหน้าจอ (Responsive Design)
